# content/generated — собранные номера

## В печать идёт этот файл

**`jasmin-print.html`** — собран из мастер-шаблона, готов к типографии.
**`jasmin-print.pdf`** — тот же номер, отрендеренный `scripts/magazine-pdf.mjs`:
12 полос по 154 × 216 мм. Это файл для печатника.
`jasmin-print-preview.pdf` — старое превью для просмотра, не для печати.

## Как пересобрать

```bash
node scripts/build-magazine.mjs                              # Jasmin
node scripts/build-magazine.mjs content/templates/<др>.json  # другой ресторан
node scripts/check-magazine-fit.mjs                          # контроль вместимости полос
node scripts/magazine-pdf.mjs                                # PDF для типографии
```

Сборка печатает число полос и ругается, если оно не кратно 4 — скрепкой такой
номер не сброшюровать.

**`check-magazine-fit.mjs` прогонять после любой правки вёрстки.** Высота полосы
фиксирована и стоит `overflow: hidden`: лишний контент не ломает макет заметно,
он молча уходит под обрез. Скрипт печатает запас каждой полосы и падает, если
где-то минус.

## Как получить PDF для типографии

```bash
node scripts/magazine-pdf.mjs [content/generated/<slug>-print.html]
```

Размер полосы берётся из `@page` самого файла — 154 × 216 мм (A5 + вылет 3 мм),
поля нулевые, фоновая графика включена. Раньше это делалось руками через
Chrome → Ctrl+P, где размер и поля легко выставить неверно, а ошибка вылезала
уже в тираже.

Полная спека — [docs/magazine-print-spec.md](../../docs/magazine-print-spec.md):
размеры фото, бумага и краски, чек-лист перед отправкой.

Полная спека (размеры фото, требования к съёмке, чек-лист перед отправкой):
[docs/magazine-print-spec.md](../../docs/magazine-print-spec.md).

## Почему старый прототип в архиве

Первая версия номера лежит в `content/archive/2026-07-jasmin-prototype/`
(`jasmin-w1-*`, `non-kabob-w1.html`, превью и фото-промпты). Она **не пригодна
для типографии** — чтобы её случайно не отправили в печать:

| Что не так | Почему это блокер |
|---|---|
| 9 полос | Скрепка требует кратности 4 — не сброшюровать |
| Нет вылетов (`148×210`, `margin: 0`) | Обложка в край → по обрезу белые полосы |
| QR на стр. 9 битый | data-URI не парсится, промо-механика полосы мертва |
| Фото 1024×1024 | ~175 dpi на обложке при норме 300; квадрат в прямоугольном окне режется вслепую |
| Шрифты с Google Fonts по сети | Печатный файл должен собираться без интернета |
| «Фото → сразу промокод −15 %» | Система так не работает: кадр → штамп (1/день) → 5 штампов → промокод |

Архив оставлен как история и источник текстов — удалять его не нужно.
